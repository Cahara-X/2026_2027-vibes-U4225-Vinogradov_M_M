# Отчет по лабораторной работе №3 «Запуск бота для реального использования»
# ТГ БОТА @itmoftmi_vmm_bot
## Цель

Научиться деплоить бота, чтобы им могли пользоваться реальные люди.

## Способ деплоя

Вариант 2, **облачный хостинг Railway**. Код загружен напрямую с компьютера через Railway CLI.

## Подготовка

- Токен и настройки хранятся в переменных окружения, `.env` исключён через `.gitignore`
- В `requirements.txt` указаны зависимости, включая `python-telegram-bot[job-queue]` для расписания
- Добавлены `Procfile` (`worker: python bot.py`) и `.python-version` (`3.12`)
- Логирование уже было настроено в `bot.py`

## Деплой

```bash
railway login
railway init
railway up
```

В настройках сервиса заданы переменные `BOT_TOKEN`, `ADMIN_IDS`, `TIMEZONE`, `DB_PATH=/data/hryuchevo.db`.

Подключён Volume с точкой монтирования `/data`. Без него база SQLite стиралась бы при каждом перезапуске контейнера.
