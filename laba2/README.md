# Отчёт по лабораторной работе №2 «Подключение бота к данным»
# ТГ БОТА @itmoftmi_vmm_bot
## Цель

Научиться подключать бота к источнику данных и работать с ним через LLM-генерацию кода.

## Выбранный тип интеграции

Вариант 3. Бот «Хрючевальня» уже хранит пользователей, блюда и оценки в SQLite (лабораторная 1). Во второй лабораторной добавлена работа с этими данными: поиск, история за период и выгрузка в файл.

## Промпт

Улучши моего Telegram-бота «Хрючевальня», добавив работу с данными из базы SQLite.

Текущий функционал бота:
Бот на python-telegram-bot v21 + SQLite. Пользователи присылают фото еды, другие оценивают
его кнопками 🐷1…🐷5. Есть /rate, /top, /antitop, /places, /my, /stats, /report для админа,
уведомления автору, «Хрючево дня» и еженедельный отчёт админам.

Новый функционал:
- /find <слово> — поиск блюд по названию без учёта регистра (в том числе кириллицы),
  с кнопками для открытия и оценки найденного блюда.
- /history [дни] — мои оценки и мои блюда за последние N дней (по умолчанию 7).
- /export — выгрузка всей моей истории в CSV-файл для Excel.

Требования:
- Код должен быть простым и понятным
- Добавить обработку ошибок
- Хорошие комментарии в коде
- Сохранить существующий функционал

## Что добавлено

| Команда | Что делает |
|---|---|
| `/find <слово>` | Ищет блюда по части названия, показывает до 10 результатов с рейтингом, местом и автором. По кнопке с номером открывается фото блюда; если оно чужое и ещё не оценено, сразу появляются кнопки оценки |
| `/history [дни]` | Показывает оценки пользователя и выложенные им блюда за последние N дней (по умолчанию 7, максимум 365), а также среднюю поставленную оценку |
| `/export` | Присылает CSV-файл со всей историей пользователя: дата, блюдо, место, цена, своя оценка, средняя оценка, число голосов |

Изменения в коде:

- новые функции работы с БД: `find_posts`, `get_user_history`, `get_export_rows`, `has_rated`;
- функция `build_csv` формирует файл в памяти, без записи на диск. Разделитель `;` и кодировка UTF-8 с BOM нужны, чтобы файл корректно открывался в русском Excel;
- время из БД (хранится в UTC) переводится в часовой пояс пользователя функцией `fmt_dt`;
- справка `/help` и README дополнены новыми командами.

Существующий функционал лабораторной 1 сохранён без изменений.

## Обработка ошибок

- `/find` без запроса, слишком короткий (меньше 2 символов) или слишком длинный (больше 50) запрос → подсказка;
- `/history` с нечисловым или выходящим за 1–365 значением → просьба ввести корректное число;
- `/export` при пустой истории → сообщение «экспортировать нечего»;
- символы `%` и `_` в поисковом запросе экранируются и ищутся как обычные символы, а не как шаблоны `LIKE`;
- открытие удалённого блюда из результатов поиска → сообщение «блюдо исчезло».
